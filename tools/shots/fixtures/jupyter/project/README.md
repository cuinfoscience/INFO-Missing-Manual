# Weekly sales

A small practice project: two weeks of made-up sales from two coffee shops, explored in a notebook.

- `data/raw/sales.csv`: the raw export, never edited by hand
- `notebooks/explore.ipynb`: a first look at the data
- `notebooks/dataframe.ipynb`: building a DataFrame by hand
- `src/clean.py`: cleaning steps the notebooks import

The data is synthetic. This project exists so that the screenshots in *Missing Manual for Information Scientists* can be retaken; see `tools/shots/fixtures/jupyter/README.md` in the book's repository.
